# Plataforma de Empregabilidade Remota para Pessoas Surdas

## 📌 Sobre o projeto
Plataforma web para conectar candidatos surdos a empresas, com foco em oportunidades de trabalho remoto ou híbrido. Toda a plataforma é construída pensando na acessibilidade para pessoas surdas.

## 💡 Diferencial
A plataforma conta com recurso de inteligência artificial para auxiliar na comunicação: a IA traduz a sinalização do profissional surdo em fala, permitindo que ele atenda ligações e converse com clientes, superando a barreira da comunicação auditiva.

## 🛠️ Tecnologias que vamos usar
- HTML
- CSS
- JavaScript

## ✨ Funcionalidades
- Cadastro de candidatos surdos
- Cadastro de empresas com vagas remotas ou híbridas
- Combinação entre candidato e vaga
- Ferramenta de IA para auxiliar a comunicação com clientes
